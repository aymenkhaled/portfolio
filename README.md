# Portfolio — React and Sanity

An earlier personal portfolio implementation using React with Sanity-related content libraries.

## Technology

- React and Create React App
- Sanity client and image utilities
- Framer Motion
- React Icons

## Local development

```bash
npm install
npm start
```

Run the production build:

```bash
npm run build
```

The application runs at [http://localhost:3000](http://localhost:3000) in development.

## Code structure

- `src/` — portfolio UI and page logic
- `public/` — static files
- `sanity_backend/` — content-management implementation

If the Sanity backend is needed, configure it using your own project credentials. Do not commit keys or tokens.
